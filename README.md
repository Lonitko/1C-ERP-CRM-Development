# 1C-ERP-CRM-Development
«Примеры разработки на платформе 1С:Предприятие 8.3».

## 📂 Структура репозитория:
*  `resume_Moroz.pdf` - актуальное резюме
*  `Portfolio_Moroz_I.O.pdf` - портфолио с реализованными поектами
* `GetCurrencyRates_NBRB.bsl` - исходный код модуля интеграции с API НБРБ и логика записи курсов в регистр сведений.
* `salary-calculations.bsl` -  исходный код модуля объекта, документа Начисление заработной платы
*  `certificate.png` -  сертификат "Основы конфигурирования в 1С и оперативный учёт"
*  `Checking_theTrust_Marker` -  код модуля формы справочника «Контрагенты» (в составе расширения конфигурации). Реализует автоматическую проверку надёжности контрагента через внешний REST API: формирует HTTP GET‑запрос с ОГРН, обрабатывает JSON‑ответ, сопоставляет показатель code_egr с таблицей статусов и обновляет реквизит «МаркерНадежности» в карточке контрагента.
